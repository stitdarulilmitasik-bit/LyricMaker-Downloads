# LyricMaker

**LyricMaker** is an Android application for creating lyric videos from audio, lyrics, photos/videos, typography, and audio-reactive visualizers.

## Features

- Audio selection and preview.
- Lyrics input with timestamped lyric lines.
- Manual lyric synchronization and timeline editing.
- Independent styling for the primary and second displayed lyric line.
- Font size and lyric color controls.
- Photo/video backgrounds.
- Audio-reactive visualizer.
- MP4 video export.
- Export progress and sharing.

## Releases

Android release builds are produced automatically from the private source repository.

Each release is built through GitHub Actions and uses protected release-signing credentials. Signing credentials and private application source code are not included in this public repository.

## Repository structure

This repository is a **public distribution repository**. It contains release information and downloadable application packages.

The application source code is maintained separately in a private repository.
